# Por feature efetiva, não por role

> Decisão migrada em 2026-09-18 do contexto temático da API (**Contratos de API** › *Views (presenter)*), que deixou de existir:
> a partir daí, cada decisão é um ADR. O texto é o original; só os links foram reapontados.

A feature `read:user:others` pode vir de role **ou** de override. Resolver por role perderia quem
tem a feature efetiva por override. A feature efetiva é a verdade.
