# `docs/specs/` — specs em negociação

Spec longa demais para caber em bullets do [`todo.md`](../todo.md): o desenho de uma fase,
de um esforço grande, ou os mapas e filhos do `/wayfinder`.

**É documento vivo, não permanente.** Enquanto o trabalho está aberto, só o
[`todo.md`](../todo.md) aponta para cá. Quando o trabalho fecha, o *porquê* migra para um
ADR ou para o arquivo temático de [`docs/context/`](../context/) e a spec é **apagada** — se
algo dela não tem dono permanente, criar o dono faz parte do fecho.

Nenhum documento permanente (ADR, `docs/context/`, `README.md`, `CLAUDE.md`, comentário de
`src/`) pode citar um caminho daqui; o `npm run docs:check` reprova quem tentar. O caminho
completo de uma ideia até o código está em [`../README.md`](../README.md).
