# `.scratch/` — rascunho, fora do git

Ideia crua, anotação de brainstorming, material que o `/grill-with-docs` vai triturar,
resultado intermediário de investigação. **Nada aqui é versionado** (só este README), e nada
aqui é permanente.

É de propósito: rascunho versionado vira documento que alguém cita, e citação de rascunho é
como uma decisão descartável acaba sustentando um ADR. O que sobreviver ao rascunho vira
spec em [`docs/specs/`](../docs/specs/); o que sobreviver à spec vira ADR ou contexto.

O caminho completo — da ideia ao código — está em [`docs/README.md`](../docs/README.md).
